    Sobre el proyecto

    Una experiencia web inmersiva para mostrar los espacios de la Institución ACOANDES de forma sencilla, visual y accesible desde computador o celular. Proyecto de integración SENA.

    Objetivo
    Que cualquier persona conozca la institución sin estar allí, recorriendo 22 espacios en fotografías panorámicas 360°.
    Experiencia
    Gira la cámara, acerca o aleja la imagen y cambia de lugar con la guirnalda de banderines, el índice, los botones, el teclado o la pantalla táctil. Cada banderín se rellena cuando visitas su espacio.
    Desarrollo
    HTML, CSS y JavaScript. Pannellum convierte cada fotografía equirectangular en una vista 360° interactiva. La música ambiental se compone en tiempo real en el navegador con la Web Audio API, por eso es libre de derechos.
    Publicación
    Preparado para GitHub Pages: se publica la carpeta completa (index.html, css, js, img y fonts).
